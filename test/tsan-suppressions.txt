# Known-benign data races in rpmalloc, intentionally suppressed so the TSAN
# stress harness can surface *real* races instead of halting on these.
#
# The page_t flag fields (has_aligned_block, is_full, ...) are packed bitfields
# sharing one 32-bit word. The owner thread is the only writer; cross-thread
# frees, and reallocations of a block in a page of another heap, as a block of
# a shared heap, only read has_aligned_block / is_full. On all supported architectures
# the naturally-aligned word access is atomic in hardware, the read flags are
# monotonic/tolerant, so a stale read is harmless. TSAN still reports the
# non-atomic write/read as a data race. See struct page_t in rpmalloc.c.
race:heap_allocate_block_aligned
race:span_deallocate_block
race:page_put_thread_free_block
race:rprealloc
race:heap_reallocate_block

# A cross-thread free reads the used block count of the page, which the owner writes without synchronization,
# to queue a page whose used blocks are then all in its thread free list. A stale count only queues a page the
# owner does not retire, or leaves the page to be adopted when the owner allocates from it. See
# page_thread_free_token in rpmalloc.c.
race:page_thread_free_token

# A heap taking a page from the orphan lists writes the page heap and first class flag while threads freeing blocks
# into the page read them on the cross-thread free path. Both the orphan heap and the new heap make a thread
# that does not own the page take the cross-thread path, and the queued flag the heap clears with release ordering
# afterwards orders the write before any read that queues the page. See heap_take_orphan_page in rpmalloc.c.
race:heap_take_orphan_page
race:heap_orphan_pages
race:page_orphan_full
